# 许吃｜懂你的每一口

一个懂你口味的本地美食社区微信小程序前端 Demo。

## 项目定位

不看大众评分，只看懂你的人。

核心循环：吃 → 分享 → 打标签 → 建立口味画像 → 找同好 → 智能推荐 → 再去吃。

## 当前版本

- 原生微信小程序
- 首页 / 附近 / 发布 / 发现 / 我的
- 菜品与店铺详情
- 许吃 / 有条件 / 不许吃
- 口味标签与口味画像
- 同好推荐
- 用户等级与勋章
- 本地 Mock 数据
- 发布页包含 AI 识别与标签生成的交互 Demo

## 使用方式

1. 使用微信开发者工具导入项目根目录。
2. 将 `project.config.json` 中的 AppID 替换为你自己的小程序 AppID。
3. 当前项目为前端 Demo，接口、登录、数据库、真实 AI 能力尚未接入。

## 目录

```text
components/  通用组件
pages/       小程序页面
utils/       Mock 数据与工具
app.js       全局逻辑
app.json     小程序配置
app.wxss     全局样式
```
