# 许吃｜懂你的每一口

本仓库为许吃本地美食同好社区微信小程序 MVP。

## 核心能力
- 附近、发现、个性化首页
- 菜品/店铺详情
- 搜索菜品、店铺、口味
- 许吃 / 有条件 / 不许吃
- 收藏、关注、评论
- 口味画像、美食人格、吃货等级与勋章
- 同好匹配与推荐理由
- 发布美食，图片上传云存储
- 微信云开发云函数 API + 云数据库

## 技术方案
前端：原生微信小程序；后端：微信云函数；数据：云数据库；文件：云存储。

首次部署前修改 `app.js` 与 `cloudbaserc.json` 中的 `YOUR_ENV_ID`。

云函数：`cloudfunctions/api`。
